# Feature
Create an application to record recipes. One recipe consists of :
 id: identifier to manage the recipes
 title: title of the recipe, for example, orange cake
 type: one of dessert, main-course, drink
 ingredients: a list of ingredients. Ingredients have name, quantity and unit
 steps: a list of steps. One step is a short text with instructions
 cooking: the information about the cooking temperature and the cooking time

 The application allows to :
 - create recipes
 - delete recipes
 - update the fields of the recipes (except the id)
 - export recipes to a JSON file (to backup the recipes)
 - import recipes from the JSON file
 - delete all the recipes
 - show all the recipes by type
 - find one recipe from its title or text in its title
